# HaloMoon Notes

HaloMoon 的独立 Markdown 学习笔记仓库。

## 最快使用方式

双击：

```text
管理笔记.cmd
```

菜单支持：

1. 新建笔记并同步；
2. 删除笔记并同步；
3. 同步已有修改；
4. 拉取远程更新。

## 分类映射

```text
notes/linux/network.md
→ https://www.halomoon.cn/notes/linux/network/

notes/programming/c-language.md
→ https://www.halomoon.cn/notes/programming/c-language/
```

所有笔记必须使用 Markdown，并包含 Front Matter。
